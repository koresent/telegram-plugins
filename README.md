# telegram-plugins

A curated collection of plugins for [exteraGram](https://github.com/exteraSquad/exteraGram) and compatible Telegram Android clients.

---

## Available Plugins

| Plugin | Description | Directory |
|---|---|---|
| **Cursor Glide** | Smooth cursor and caret animation with dynamic trail stretching and custom color palettes | [`cursor_glide/`](cursor_glide/) |
| **Chat Web Tabs** | Custom web apps and pinned web tabs with persistent sessions for Telegram chats | [`chat_web_tabs/`](chat_web_tabs/) |

---

## How to Install

1. Navigate to the desired plugin folder (e.g. [`cursor_glide/`](cursor_glide/) or [`chat_web_tabs/`](chat_web_tabs/)).
2. Download the `.plugin` file.
3. Open the file in **exteraGram** (or send it to your Saved Messages and tap to install).
4. Go to **Settings** > **Plugins** to enable and configure the plugin.
