# Telegram plugins

My personal collection of plugins for [exteraGram](https://github.com/exteraSquad/exteraGram) and its forks.

---

## Available Plugins

| Plugin            | Description                                                                               | Directory                          |
| ----------------- | ----------------------------------------------------------------------------------------- | ---------------------------------- |
| **Cursor Glide**  | Smooth cursor and caret animation with dynamic trail stretching and custom color palettes | [`cursor_glide/`](cursor_glide/)   |
| **Chat Web Tabs** | Custom web apps and pinned web tabs with persistent sessions for Telegram chats           | [`chat_web_tabs/`](chat_web_tabs/) |
| **Bot Web Tabs**  | Custom web app buttons with persistent sessions for Telegram bots                         | [`bot_web_tabs/`](bot_web_tabs/)   |
| **Local Renamer** | Purely visual local display name overrides for bots, groups, channels, and users          | [`local_rename/`](local_rename/)   |

---

## How to Install

1. Navigate to the plugin folder.
2. Download the `.plugin` file and send it to your **Saved Messages** in exteraGram.
3. In exteraGram, open **Settings** > **Plugins** and enable **Unknown sources**.
4. Tap the `.plugin` file in your chat and tap **Install**.
5. Open **Settings** > **Plugins** to enable and configure the plugin.
